# rusix

An incremental Rust rewrite of the Linux kernel for a declared VM/server target,
followed by migration of selected userspace components.

Start with the [project status](rusix/README.md),
[accepted architecture](rusix/docs/adr/0002.md), and
[contributor guide](rusix/CONTRIBUTING.md).
[Progress](rusix/PROGRESS.md) records executed checks and remaining work;
[Phase 1](rusix/docs/PHASE1.md) defines the next delivery gates.

This public repository is a fork of `torvalds/linux`. Linux history, licensing,
attribution, and its original [README](README) are retained. Project documents,
configuration, and tooling live under `rusix/`. See [COPYING](COPYING),
[LICENSES](LICENSES/), and each file's SPDX identifier.
